/techhelp

Helps troubleshoot a tech problem with simple, numbered steps.

The full prompt

/techhelp Help me fix a tech problem. Device and model: [device]. Problem: [what happens]. What I've tried: [steps]. What I see on screen: [message].
Give me numbered steps in plain words, easiest fixes first, and say what I should see after each step. If you need more details, ask me first.

Replace the highlighted [brackets] with your own details, then send.

What you're asking

You ask for help with a device problem. You get numbered fixes, easiest first, or questions if details are missing.

Give it

  • Device and model
  • Exactly what happens
  • What you already tried
  • Any error message

Check: Menus differ by model and software version; back up before resetting anything.

Filled-in example

/techhelp Help me fix a tech problem. Device and model: iPhone 14. Problem: it won't charge past 80%. What I've tried: a different cable and restarting. What I see on screen: a message about charging being on hold.
Give me numbered steps in plain words, easiest fixes first, and say what I should see after each step. If you need more details, ask me first.
