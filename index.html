Slack

Official list

Built into every Slack workspace. Type / in the message box.

Some commands can be limited to admins in your workspace.

  • /remindSets a reminder for you, someone else or a channel.
  • /statusSets you to away or active.
  • /dndDo Not DisturbTurns Do Not Disturb on or off to pause notifications.
  • /huddleStarts a huddle (a quick audio call) in the current conversation.
  • /msgMessageSends a message to a person or a channel without leaving where you are.
  • /inviteAdds someone to a channel.
  • /leaveLeaves the current channel.
  • /topicSets the topic shown at the top of the channel.
  • /muteMutes or unmutes a conversation.
  • /searchSearches messages and files.
  • /shrugAdds ¯\_(ツ)_/¯ to the end of your message.

Obsidian

Official list

Turn on Slash commands in Settings, then Core plugins. Type / at the start of a line or after a space.

Obsidian matches loosely, so a few letters find any command. These are the words that land on each one.

  • /tableRuns Insert table to add a Markdown table.
  • /calloutRuns Insert callout to add a callout block.
  • /codeblockRuns Insert code block.
  • /templateRuns Templates: Insert template. Needs the Templates core plugin.
  • /dateRuns Templates: Insert current date. Needs the Templates core plugin.
  • /todayRuns Daily notes: Open today's daily note. Needs the Daily notes core plugin.
  • /propertyRuns Add file property, for tags, dates and other note details.
  • /checkboxRuns Toggle checkbox status on the current line.

The list changes by editor. Type / in Copilot Chat to see what yours offers.
