/readinglist

Suggests what to read to get up to speed on a topic.

The full prompt

/readinglist I have [hours] hours to get up to speed on [topic] for [reason]. Suggest a reading plan in order: what to read first, why, and how long each takes. Prefer well-known, reliable sources and say which type each is (book, report, article, course). Only list sources you are confident exist; if unsure, describe what to search for instead.

Replace the highlighted [brackets] with your own details, then send.

What you're asking

Asks the AI for an ordered reading plan that fits your time. You get a short list of sources with reasons and time estimates.

Give it

  • The topic
  • Time you have
  • Why you need it
  • Your current level

You need: For the newest sources, an AI app that can search the web.

No web search? Ask for topics and search terms, then look them up yourself.

Check: Confirm each title and link exists before you share the list.

Filled-in example

/readinglist I have 3 hours to get up to speed on AI governance basics for a policy meeting. Suggest a reading plan in order: what to read first, why, and how long each takes. Prefer well-known, reliable sources and say which type each is (book, report, article, course). Only list sources you are confident exist; if unsure, describe what to search for instead.
